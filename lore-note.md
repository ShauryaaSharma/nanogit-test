# Lore — test note

This is a throwaway test file for **Lore**, the engineering decision memory.

It exists only to open a pull request and confirm that Lore reads the PR,
posts its "what I understood / what I'll remember" comment, and inscribes the
decision into the Canon once merged.

## Why
We wanted an end-to-end check that the GitHub App captures a real PR from this
repo — not the seed corpus — and that the summary reflects the actual content.
